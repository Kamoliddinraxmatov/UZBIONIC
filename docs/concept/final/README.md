# UZBIONIC final reference model (approved 2026-11-03)

Kamoliddin chose these three images as THE model we print. All visual work (outer covers, panels, palm pads) follows them; the CadQuery skeleton must fit inside.

- `uzbionic-final-1.jpg`: top view, back of hand, light background
- `uzbionic-final-2.jpg`: same top view, dark background
- `uzbionic-final-3.jpg`: three-quarter side view, elbow to fingertips

Look: graphite/slate forearm shell with "UZBIONIC" + flag mark, sun "UZB" emblem on the back of the hand, carbon-texture finger segments with round joint caps, upper-arm cup with crescent mark. Printer: Bambu Lab P1S. Materials: PETG/nylon skeleton, ASA covers, TPU 85A soft parts (low infill for softness). Flag and emblem use needs a legal check (see docs/15-brand-concept-v3.md).
